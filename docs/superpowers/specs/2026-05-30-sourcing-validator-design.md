## Problem Statement

소싱 후보 키워드를 발굴했을 때 "이게 진짜 팔릴까?"를 검증하는 체계적인 방법이 없다.
수요·계절성·경쟁 구조를 한 번에 보고 종합 진입 판정을 내려주는 도구가 필요하다.

---

## Solution

키워드 하나를 입력하면 Claude가 Naver 데이터를 분석해 소싱 진입 가능 여부를 판정하는 **로컬 전용 웹 앱**.

- 별도 프로젝트 (`~/Desktop/projects/sourcing-validator/`) — smart_seller_studio에 통합 안 함
- Claude Max 플랜 사용 (`claude -p` subprocess, advertise 프로젝트 패턴 그대로)
- Naver 4종 API로 데이터 선수집 → Claude 일괄 분석 → SSE 스트리밍 출력

### API 흐름

```
POST /api/validate { keyword: "텀블러" }
  ↓ 병렬 수집
  ① DataLab: 12개월 검색량 트렌드 (NAVER_CLIENT_ID/SECRET)
  ② 자동완성: 연관 키워드 목록 (인증 불필요, ac.search.naver.com)
  ③ 쇼핑 상품수: 경쟁 강도 (네이버 쇼핑 검색)
  ④ 웹검색: 최신 뉴스·트렌드 (네이버 뉴스 검색 API)
  ↓
  claude -p "<분석 프롬프트>" --output-format stream-json
  ↓ SSE
  프론트엔드: 실시간 텍스트 스트리밍 → 최종 판정 카드
```

### Claude 연동 방식

`advertise` 프로젝트의 `claude_ai.py` 패턴을 Node.js로 포팅:

```typescript
// src/lib/claude.ts
import { execFile } from 'child_process';

export function runClaude(prompt: string): Promise<string> {
  return new Promise((resolve, reject) => {
    execFile('claude', ['-p', prompt, '--output-format', 'text'], 
      { timeout: 120_000 },
      (err, stdout, stderr) => {
        if (err) reject(new Error(stderr));
        else resolve(stdout.trim());
      }
    );
  });
}

export function streamClaude(prompt: string): AsyncGenerator<string> {
  // stream-json output → SSE 파이프
}
```

## 데이터 수집 API

| 도구 | API | 인증 |
|------|-----|------|
| DataLab 트렌드 | `POST https://openapi.naver.com/v1/datalab/search` | NAVER_CLIENT_ID/SECRET |
| 자동완성 | `GET https://ac.search.naver.com/nx/ac?q={keyword}` | 불필요 |
| 쇼핑 상품수 | `GET https://openapi.naver.com/v1/search/shop.json?query={keyword}&display=1` | NAVER_CLIENT_ID/SECRET |
| 뉴스 검색 | `GET https://openapi.naver.com/v1/search/news.json?query={keyword}&display=3` | NAVER_CLIENT_ID/SECRET |

## Constraints

- 로컬 전용 — Vercel 배포 없음

## Success Criteria

- 키워드 입력 → 30초 내 판정 결과
- Claude 분석이 실시간으로 화면에 흘러들어옴
- 진입 추천/보류/포기 + 구체적 근거가 명확하게 표시됨
- `npm run dev`로 바로 실행 가능 (추가 설정 없이)
