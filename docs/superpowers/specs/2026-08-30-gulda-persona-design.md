# 굴다 페르소나 — AI 모델에 정체성과 집을 부여한다

- **작성일**: 2026-08-30
- **대상**: `model_f_c` (여성 C · 건강 발랄)
- **채널**: 발굴템 연구소(유튜브) · `cheongyeon.corp`(인스타)

## 배경

`model-registry.ts`의 페르소나 5명은 **외모 프리셋일 뿐이다.** `label`이 「여성 C · 건강 발랄」이고 `bestFor`가 상품 매칭 힌트라, 이름·성격·말투·생활이 없다. 캐릭터 시트가 얼굴을 고정하지만 **그 사람이 누구인지는 어디에도 없다.**

2026-08-30 카디건 릴스를 만들며 두 가지가 드러났다.

1. **얼굴만 고정해서는 「그 사람의 집」이 만들어지지 않는다.** 같은 프롬프트로 3색 착용컷을 생성하자 방 구조가 매번 달라졌다(커튼 왼쪽 / 창 중앙 / 소파 왼쪽).
2. **참조 3장 상한이 배경 고정을 막는다.** 의류는 캐릭터 시트·착용 참조·제품 누끼로 세 자리가 이미 찬다.

유튜브 채널을 운영하려면 컨셉이 필요하고, 컨셉은 **반복 등장하는 인물과 공간**에서 나온다.

## 목표

`model_f_c`에 **이름·정체성·말투·집**을 부여해 발굴템 연구소의 고정 호스트로 만든다. 최종적으로 페르소나 5명 전원에 적용하되 **이번 범위는 여성 C 하나**다.

### 범위 밖

- 나머지 페르소나 4명의 캐릭터 설정
- 굴다가 스레드·블로그에 직접 글을 쓰는 것 (현재 설계에서 굴다는 영상 안에만 존재한다)
- 서사형 에피소드 연재

## 캐릭터 프로필

| 항목 | 설정 |
|---|---|
| 이름 | **굴다** (「발굴템」에서 딴 애칭) |
| 직함 | **발굴템 연구소 연구원** |
| 나이대 | 30대 초반 |
| 생활 | 코스트코 단골. 집이 주 무대이고 장보기·살림·정리가 일상 |
| 성격 | 잘 사는 사람이 아니라 **사고 나서 후회도 하는 사람** — 실패담이 있어야 추천이 믿긴다 |
| 말투 | **높임말 구어체** — `~잖아요` `~더라고요` `~거든요` `~네요` |
| 금지 | `~습니다` 정중체 · 반말 · 과장 단정(`최고예요`) · 번역투 · 부정문 제목 |
| 문장 끝 | 마침표를 찍지 않는다 |

**AI라는 사실을 컨셉 전면에 둔다.** 채널 설명과 고정 댓글에 *"발굴템 연구소의 AI 연구원"*으로 명시하되, **영상 안에서는 반복하지 않는다** — 매 편 밝히면 콘텐츠가 아니라 고지가 된다.

### 화자 분리

| 화자 | 어디 | 말투 |
|---|---|---|
| 사업자 본인 | 스레드 본문 · 블로그 | 반말 구어체 (기존 유지) |
| **굴다** | 영상 자막·나레이션 · 채널 설명 · 고정 댓글 | **높임말 구어체** |

말투가 갈리는 것이 정상이다. 스레드는 사업자가 말하고 영상은 굴다가 말한다.

## 씬 라이브러리

굴다의 집을 고정한다. 상품군을 역산해 세 곳으로 시작한다.

| 씬 | 담는 상품 | 우선순위 |
|---|---|---|
| 거실 | 의류·홈리빙 | 1 (기존 컷 있음) |
| 부엌·싱크대 | 요거트·초콜릿 무스·시리얼·주방템 | 2 |
| 현관 | 택배 언박싱·나가는 옷·신발 | 3 |
| 욕실 | 핸드워시·비누·립스틱 | 나중 |
| 베란다·주차장 | 캠핑·세차·펫 | 나중 |

각 씬은 **기준 이미지 1장 + 고정 소품 문장**으로 정의한다. 문장은 참조를 넣을 자리가 없을 때의 대체 수단이다.

### 참조 3장 제약과 해법

의류 생성에서 세 자리가 이미 찬다(캐릭터 시트 · 착용 참조 · 제품 누끼).

| 방법 | 내용 | 상태 |
|---|---|---|
| ① 상품 참조 합치기 | 착용 참조와 제품 누끼를 한 장으로 좌우 합성해 자리를 비운다 | **미검증 — 먼저 실험한다** |
| ② 배경을 문장으로 | 참조 없이 소품·배치를 프롬프트에 서술 | 정밀도 낮음 (2026-08-30 실패) |
| ③ 씬별로 다르게 | 식품·잡화는 상품 참조가 한 장이라 배경 시트를 그냥 넣는다 | 즉시 가능 |

**①을 먼저 실험하고 실패하면 ③으로 간다.** 의류만 특수 케이스다.

## 코드 구조

「누가」와 「어디서」를 분리한다. 페르소나는 5명으로 고정이지만 씬은 계속 늘어난다.

### `src/lib/ai/model-registry.ts` 확장

```ts
export interface CharacterProfile {
  name: string;          // '굴다'
  title: string;         // '발굴템 연구소 연구원'
  ageBand: string;       // '30대 초반'
  setting: string;       // 한 줄 배경
  voiceRules: string[];  // 말투 규칙
  forbidden: string[];   // 금지 표현
}

export interface ModelPersona {
  /* 기존 5개 필드 그대로 */
  character?: CharacterProfile;
}
```

`character`는 **선택 필드**다. 굴다만 채우고 나머지 넷은 지금처럼 외모 프리셋으로 계속 동작한다.

### 신규 `src/lib/ai/scene-registry.ts`

```ts
export interface SceneSheet {
  id: string;         // 'home_living'
  personaId: string;  // 'model_f_c' — 누구의 집인가
  label: string;      // '거실'
  sheetPath: string;  // Supabase scene-sheets/ 경로
  fixtures: string;   // 고정 소품 문장
  bestFor: string;    // 어떤 상품군
}
```

### 프롬프트 조립 함수

전부 순수 함수이며 테스트를 붙인다.

| 함수 | 하는 일 |
|---|---|
| `buildSceneLock(scene)` | 배경 고정 지시문 생성 |
| `buildCharacterVoice(profile)` | 자막·카피용 말투 지시문 생성 |
| `composeReferences(persona, scene, product)` | **참조 3장 안에 배치. 넘치면 씬을 `fixtures` 문장으로 강등하고 그 사실을 반환한다** |

**버리는 순서는 고정한다: 씬 → 착용 참조 → 제품 누끼.** 인물 시트와 제품 누끼는 절대 버리지 않는다 — 앞은 캐릭터 정체성이고 뒤는 상품 정확성이라, 둘 중 하나가 빠지면 그 컷은 쓸 수 없다.

`composeReferences`가 핵심이다. 참조 상한을 코드가 알고 판단하게 두면, 의류처럼 상품 참조가 둘인 경우에도 조용히 깨지지 않는다.

## 제작 워크플로우

| 단계 | 빈도 | 내용 |
|---|---|---|
| ① 씬 시트 제작 | 1회 | 거실·부엌·현관 기준 이미지 생성 후 3곳에 저장 |
| ② **씬 검증** | 1회 | 같은 씬으로 3장 생성. **합격 기준: 세 장에서 주요 가구의 종류·상대 위치·개수가 같을 것**(소파가 오른쪽에 하나, 창이 왼쪽 등). 조명·각도의 미세 차이는 통과로 본다 |
| ③ 착용컷·씬컷 생성 | 매 편 | 인물 시트 + 씬 시트 + 상품 |
| ④ i2v | 매 편 | Seedance — **모델을 명시한다.** 미지정 시 2.5가 잡혀 21배가 된다 |
| ⑤ 자막·카피 | 매 편 | `buildCharacterVoice`로 굴다 말투 적용 |

**②는 생략할 수 없다.** 씬 시트가 실제로 배경을 고정하는지 확인되기 전에는 편당 제작에 쓰지 않는다. 실패하면 프로필만 적용하고 배경은 매번 새로 그린다.

## 테스트

| 대상 | 방식 |
|---|---|
| `buildSceneLock` · `buildCharacterVoice` | 순수 함수 — 입력 대비 출력 문자열 검증 |
| `composeReferences` | **참조가 넘칠 때 씬이 강등되는지**, 강등 사실이 반환되는지 |
| `findPersona` · 씬 조회 | 없는 id에 null을 주는지 |
| 씬 일관성 | 🔴 **육안 검증** — 자동화 불가. 워크플로우 ②단계 |

## 오류 처리

- 씬 시트가 Supabase에 없으면 `fixtures` 문장으로 대체하고 경고를 남긴다 — 생성을 중단하지 않는다
- `character`가 없는 페르소나는 말투 지시문 없이 기존 동작을 유지한다
- 참조가 넘쳐 씬이 강등되면 호출자에게 알린다. 조용히 떨어뜨리지 않는다

## 열린 질문

- **상품 참조 합치기(①)가 실제로 되는가.** 좌우로 붙인 이미지를 모델이 두 개의 참조로 읽는지 확인되지 않았다
- **씬 시트가 배경을 고정하는가.** 2026-08-30 실패의 원인이 참조 부재인지 모델 한계인지 아직 갈리지 않았다
- 나머지 페르소나 4명에게 언제 캐릭터를 부여할 것인가
- 굴다의 목소리(TTS)를 고정할 것인가 — 이번 범위 밖이지만 영상에 나레이션이 붙으면 필요해진다
