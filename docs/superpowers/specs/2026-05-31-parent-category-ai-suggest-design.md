# 대분류 AI 추천 — 설계 문서

Generated by /brainstorming on 2026-05-31
Status: APPROVED

---

## Problem Statement

소싱 캘린더의 대분류(잡화·뷰티/위생 등 6개)는 `src/lib/categories.ts`에 하드코딩되어 있다.
소분류는 AI 추천으로 교체할 수 있지만, 대분류 자체는 사용자가 수동으로만 관리해야 한다.
AI가 현재 대분류를 참고해 완전히 새로운 관점의 대분류+소분류 트리를 한 번에 추천하면,
소싱 카테고리 탐색 시간을 줄이고 미처 생각 못한 카테고리를 발견할 수 있다.

---

## Solution

헤더 우측에 **"✦ 대분류 AI 추천"** 버튼을 추가한다.
클릭 시 Claude Haiku가 현재 대분류 목록을 참고해 **새로운 대분류 6~8개 + 각 소분류 5~7개**를
한 번의 호출로 생성하고, 전체 카테고리 트리를 즉시 교체한다.

모든 Claude 호출은 **`callClaude()`** (`src/lib/ai/claude-cli.ts`) 를 사용한다.
— 로컬: Claude Code OAuth (Max Plan), 배포: `ANTHROPIC_API_KEY` 자동 폴백.

기존 `suggest-subcategories` route도 동일하게 `callClaude()`로 교체한다.

## API

### POST `/api/calendar/suggest-categories`

Request:
```json
{ "currentCategories": ["잡화", "뷰티/위생", "생활용품", "패션잡화", "스포츠", "식품"] }
```

Response (성공):
```json
{
  "categories": [
    {
      "name": "반려동물용품",
      "subcategories": ["강아지 간식", "고양이 장난감", "펫 침대", "반려동물 의류", "반려동물 목욕용품"]
    }
  ],
  "suggestedAt": "2026-05-31T10:00:00Z"
}
```

Response (에러):
```json
{ "error": "카테고리 추천에 실패했습니다." }
```

#### Claude 프롬프트

```
System:
당신은 쿠팡 소싱 전문가입니다.
쿠팡에서 단품으로 공략 가능한 대분류와 각 대분류의 소분류를 추천합니다.
규칙:
- 대분류: 6~8개, 너무 넓지 않은 적절한 범위 (예: "반려동물용품" 적합 / "생활" 너무 넓음)
- 각 대분류당 소분류: 5~7개, 쿠팡 단품 판매 가능한 구체적 카테고리
- 브랜드명 제외
반드시 JSON 배열 형식만 반환하세요.

User:
현재 대분류: {currentCategories.join(', ')}

현재와 다른 새로운 관점의 대분류와 소분류를 추천해 주세요.
중복 없이, 소싱 유망한 카테고리 위주로 구성해 주세요.
JSON만 반환: [{"name": "반려동물용품", "subcategories": ["강아지 간식", ...]}, ...]
```

모델: `haiku` (callClaude 별칭 → `claude-haiku-4-5-20251001`)
max_tokens: 기본값 (callClaude 내부 처리)

#### 에러 처리

| 상황 | 처리 |
|------|------|
| currentCategories 없음 | 400 반환 |
| JSON 파싱 실패 | 500 + 에러 메시지 반환 (교체 없음) |
| callClaude 실패 | 500 + 에러 메시지 반환 (교체 없음) |

> 대분류 추천 실패 시 **기존 목록을 보존**한다 (소분류 추천의 폴백 방식과 다름).
> 대분류는 소분류보다 영향 범위가 크므로 실패 시 교체하지 않는다.

## UI

### 버튼 위치

```
┌─────────────────────────────────────────────────────────────────────┐
│ 소싱 캘린더                              [✦ 대분류 AI 추천]          │  ← 헤더
│ 카테고리별 소싱 후보 관리 · AI 소분류 추천                           │
├─────────────────────────────────────────────────────────────────────┤
│ [잡화] [뷰티/위생] [생활용품] [패션잡화] [스포츠] [식품]  [✦ 소분류 AI 추천] │  ← 탭 바
├─────────────────────────────────────────────────────────────────────┤
│ [텀블러 AI] [머그컵 AI] [물병 AI] ...   [+ 추가]                    │  ← 소분류 그리드
```

### 상태

| 상태 | "✦ 대분류 AI 추천" 버튼 | 탭 바 |
|------|------------------------|-------|
| 기본 | 보라색 테두리, 연보라 배경 | 정상 |
| 로딩 | "추천 중..." 비활성화 | opacity 0.5 |
| 완료 | 기본 상태로 복귀 | 새 탭에 `AI` 뱃지 |
| 에러 | 기본 상태로 복귀 | 탭 바 유지 (교체 없음) |

### 동작 흐름

1. "✦ 대분류 AI 추천" 클릭
2. `suggestCatLoading = true`, 탭 바 흐리게
3. `POST /api/calendar/suggest-categories` 호출
4. 성공: 전체 `categories` 교체 → `persistCategories(updated)`
5. `activeCatId` → 첫 번째 새 대분류로 리셋
6. `activeSubId`, `suggestedIds` 초기화
7. `suggestedCatIds` = 새 대분류 id Set (보라색 `AI` 뱃지 표시)
8. `suggestCatLoading = false`
9. 실패: `suggestCatLoading = false`, 에러 토스트 없음 (기존 목록 유지)

확인 다이얼로그 없음 — 즉시 교체.
