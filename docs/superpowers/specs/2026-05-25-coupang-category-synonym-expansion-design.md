# 쿠팡 카테고리 동의어 확장 — 설계 문서

**날짜**: 2026-05-25  
**범위**: AI 상품 등록 > Step 2 > 카테고리·재고 > CategorySearch  
**상태**: 승인됨

---

## 배경 및 문제

AI 상품 등록 Step 2의 `CategorySearch` 컴포넌트는 사용자가 입력한 키워드로 쿠팡 카테고리 트리를 검색한다. 현재는 입력 키워드를 그대로 검색하기 때문에, 동의어/유사어를 입력하면 적절한 카테고리를 찾지 못하는 경우가 있다.

예시: "등산가방"을 입력해도 쿠팡 트리에 "배낭"으로 등록된 카테고리가 있으면 검색되지 않음.

---

## 목표

- 사용자가 입력한 키워드를 정적 동의어 매핑 테이블로 확장해, 관련 쿠팡 카테고리가 더 많이 검색되도록 한다.
- 클라이언트(`CategorySearch`) 변경 없이 서버 사이드에서만 처리한다.
- 매핑 테이블은 독립 파일로 관리해 추후 확장이 용이하게 한다.

---

## 아키텍처

```
[클라이언트: CategorySearch]
  └─ GET /api/listing/coupang/categories?keyword=등산가방
          │
          ▼
[서버: categories/route.ts]
  1. expandKeyword("등산가방")
     → ["등산가방", "배낭", "트레킹백", "하이킹백"]
  2. 각 키워드로 category tree 검색 (병렬, Promise.allSettled)
  3. displayItemCategoryCode 기준 중복 제거
  4. predictCategory는 원본 keyword만 전달 (기존 동작 유지)
  5. 병합 결과 반환
          │
          ▼
[신규: src/lib/listing/category-synonyms.ts]
  export function expandKeyword(keyword: string): string[]
```

export function expandKeyword(keyword: string): string[] {
  const trimmed = keyword.trim();
  const synonyms = SYNONYM_MAP[trimmed];
  if (!synonyms) return [trimmed];
  return [trimmed, ...synonyms];
}

### 2. `src/app/api/listing/coupang/categories/route.ts` (수정)

`expandKeyword`를 import하고, 기존 단일 트리 검색을 병렬 다중 검색으로 교체한다.

```typescript
import { expandKeyword } from '@/lib/listing/category-synonyms';

// 기존: searchCategoryTree(keyword) 1회
// 변경:
const keywords = expandKeyword(keyword);
const treeResults = await Promise.allSettled(
  keywords.map((kw) => searchCategoryTree(kw))
);

const seen = new Set<number>();
const mergedTree = treeResults
  .flatMap((r) => (r.status === 'fulfilled' ? r.value : []))
  .filter((cat) => {
    if (seen.has(cat.displayItemCategoryCode)) return false;
    seen.add(cat.displayItemCategoryCode);
    return true;
  });
```

## 에러 처리

| 시나리오 | 처리 |
|---|---|
| 일부 동의어 트리 검색 실패 | `Promise.allSettled`로 나머지 결과 정상 반환 |
| 모든 검색 실패 | 빈 배열 반환 (기존 동작 동일) |
| 매핑 없는 키워드 | `[keyword]` 반환, 기존과 완전 동일 |

## 테스트 전략

- `expandKeyword` 단위 테스트: 매핑 있는 키워드(동의어 포함 배열 반환), 없는 키워드(원본만 반환), 공백 trim 처리
- `/api/listing/coupang/categories` 통합 테스트: `searchCategoryTree` mock으로 병렬 호출 횟수 확인, 중복 `displayItemCategoryCode` 제거 확인

## 범위 제외

- 네이버 카테고리 API: 별도 동의어 처리 없음 (Naver 검색은 자체 형태소 분석기로 처리됨)
- 부분 매칭 (예: "등산" 입력 시 "등산가방" 매핑 적용): 오탐 위험으로 제외
- 동의어 역방향 매핑 (예: "배낭" 입력 시 "등산가방" 연결): 1차 범위 제외
