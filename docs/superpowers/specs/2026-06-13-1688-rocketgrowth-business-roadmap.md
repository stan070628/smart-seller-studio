1# 1688 사입 → 로켓그로스 입점 사업 시작 로드맵

> 작성일: 2026-06-13
> 대상: 쿠팡/스마트스토어 판매 경험은 있으나 1688 중국 사입·로켓그로스는 처음인 셀러
> 출발 조건: 팔 아이템 백지 상태 / 브랜딩·지재권 분쟁 중시 / 초기 예산 300~500만원

## 채택 방향

**위탁 선검증 → 사입 전환 (방향 A) + 지재권·브랜딩 사전 반영 (방향 C 일부)**

검토한 대안:
- **방향 A (채택)**: 위탁으로 상품성을 데이터 검증한 뒤, 통과한 상품만 1688 사입. 한정 예산을 회송·악성재고로 날릴 위험 최소화.
- 방향 B: 바로 소량 사입 테스트. 실무를 빨리 배우지만 검증 안 된 상품에 돈이 먼저 묶임.
- 방향 C: 학습 트랙 + 실전 트랙 병행. 지재권을 처음부터 차단하나 초반 부담.

→ "백지 상태 + 지재권 걱정 + 한정 예산"이 동시에 있어, **검증 전에 돈을 넣는 것이 최대 리스크**. 지재권은 아이템 고르는 순간부터 작동해야 하는 필터이므로 Phase 1부터 반영.

## 핵심 설계 원칙

1. **돈은 검증 뒤에 나간다** — 위탁(0원)으로 먼저 거르고, 통과 상품에만 사입비 투입. 500만원 중 100만원은 끝까지 비상 예비금으로 보존.
2. **지재권은 단계가 아니라 필터다** — Phase 1부터 모든 후보를 KIPRIS·캐릭터·브랜드 로고 기준으로 거름. 사고는 "고르는 순간" 정해짐.
3. **브랜딩은 사입과 동시 출발** — 사입 결정(Phase 3) 시점에 상표출원 시작. 등록까지 12~18개월이라 미루면 손해.

## 의도적으로 뺀 범위 (YAGNI)

- KC인증 필수 카테고리(전기·유아·식품·유아의류) → 첫 아이템에서 제외 (인증비가 첫 사입 자본 초과 가능)
- 자체 OEM 공장 풀커스텀 → 첫 사이클은 스티커 라벨 수준 브랜딩까지만

|---|---|---|---|
| **Phase 0** 사전무장 | Week 1 | 지재권·브랜딩·로켓그로스 기본기 + 회피 카테고리 확정 | 0원 |
| **Phase 1** 아이템 발굴 | Week 1~2 | 네거티브 필터 → 위탁 후보 10~15개 + KIPRIS 1차 검사 | 0원 |

## Phase 0 — 사전무장 (Week 1, 돈 안 듦)

### (a) 회피 카테고리 확정 — "안 팔 것"부터 못 박기
- KC인증 필수: 전기용품, 유아용품, 식품, 유아의류 → 제외
- 캐릭터/유명브랜드 유사 디자인 → 제외
- 시즌 한정(크리스마스·설·할로윈) → 제외
- 최장변 50cm 초과 → 제외 (그로스 보관료 폭증)

### (b) 지재권 기본기 — KIPRIS 사용법 익히기
- KIPRIS(특허청 무료 검색)에서 상표·디자인·특허 검색법 숙지
- 즉시 거르는 신호 3종:
  - 상품에 캐릭터 인쇄
  - 유명 브랜드 유사 로고·폰트
  - 특이한 잠금·접이 구조 (기능특허 위험)

### (c) 로켓그로스 룰 숙지 — 회송 3대 기준 미리 읽기
- **포장**: 낱개 개별포장 필수, 중국발 냄새(곰팡이·담배) 금지
- **사이즈**: 실측 오차 ±2cm, 부피무게 = (가로×세로×높이)÷6000
- **바코드**: CODE128, 300dpi 이상, 박스 측면 부착, 윙 등록 SKU와 일치
- 수수료 구조 감 잡기: 생활용품 약 10~15% + 보관료(부피·기간 연동)

## Phase 1 — 아이템 발굴 (Week 1~2)

### 적합 상품 기준선
- 최장변 50cm·무게 25kg 이하
- 마진율 40%+ (관세·배송·수수료 다 뺀 기준)
- 디자인 단순·기능 위주
- 월 검색량 3,000~30,000
- 경쟁 상품수 500개 미만 / 상위 상품 리뷰 50개 미만
- 저위험 카테고리 예: 수납박스·주방소품·청소도구·욕실용품

### 키워드 발굴 순서
1. 쿠팡 검색창 자동완성으로 세부 키워드 수집
2. 검색 후 1페이지 상위 3개 평균 리뷰 50개 미만 → 진입 여지 있음
3. 후보 10~15개 추리기
4. 각 후보 KIPRIS 1차 검사 → 통과한 것만 Phase 2로

> ⚠️ 함정: "내가 좋아하는 상품" 말고 **데이터가 팔린다고 말하는 상품**으로 고를 것.

## Phase 2 — 위탁 검증 (Week 3~4, 도구비 ~20만원)

후보 상품을 위탁(무재고)으로 등록해 2주간 데이터 수집. 목적은 "이거 진짜 팔리나?"를 내 돈 안 묶고 확인.

### 위너 판정 기준 (2주 누적, 5개 전부 통과해야 사입)
- 클릭 100건+
- 전환율 1.5%+
- 광고 ROAS 250%+
- 판매 5건+
- 별점 4.0+

미달 상품은 즉시 폐기 → 통과한 2~3개만 다음 단계로.

---

## Phase 3 — 1688 사입 전환 (Week 5~8, 100~150만원)

- **계정**: 1688 가입 + 한국카드 등록 (동결 회피법대로 진행)
- **셀러 검증**: 3곳 비교, 가격차 5% 미만이면 응대속도로 결정 (24h 무응답 = 탈락)
- **지재권 2차**: KIPRIS 재확인 + 셀러에게 "타 브랜드 권리 없음" 서면 확인받고 **캡처 보관** (분쟁 증거)
- **발주**: SKU당 50~100개 소량. 100만원을 한 SKU에 몰빵 금지
- **수입**: 첫 2~3회는 수입대행지 이용 (검수+라벨+입고 원스톱)
- **검수**: 회송 3대 기준 자가검수 (냄새·실측·바코드 해상도)
- **브랜딩 동시 출발**: 상표출원 시작 (등록 12~18개월). 초반은 스티커 라벨 → MOQ 차면 인쇄 전환
  - 출원 전 KIPRIS에서 브랜드명·로고 선행상표 검색 필수

### 수입 원가 구조
```
실제 원가 = (1688 단가 × 환율) + 관세 8% + 수입VAT 10% + 국제배송비 + 통관비
```

## Phase 4 — 운영·위너 점유 (Week 9~12, 150~200만원)

- **광고**: AI 스마트광고로 1~2주 데이터 수집 → 손익분기 넘으면 매출최적화 전환
- **쿠팡 광고 보고서 보정**: 쿠폰·취소·광고비 부가세 미반영으로 실제보다 좋게 보임
  ```
  최소 광고수익률 = (판매가 ÷ 마진) × 1.1 × 100
  ```
- **위너 점유 30%+** 달성 → 사입 증량. 미달 시 위너분리 (옵션분리·신규 노출상품ID)
- **재고 회전 7~30일**: 7일치 이하로 떨어지기 전 재발주 (품절 = 알고리즘 페널티 2주)

---

## 지재권 분쟁 — 실제 사고 패턴 (상시 참조)

1. **캐릭터 인쇄 상품**: 디즈니·산리오·마블 등. 저작권자 신고 → 판매정지 + 손해배상. 1688 셀러는 책임 안 짐, 한국 셀러가 전부 부담.
2. **유명 브랜드 유사 디자인**: "비슷하게 생겼을 뿐" 논리는 상표권 소송에서 안 통함.
3. **기능특허 침해**: 잠금/접이/특수코팅 구조에 한국 특허. 겉보기 일반 상품도 분쟁 대상.

### 사전 차단 체크리스트
- [ ] KIPRIS에서 핵심 디자인/기능 특허 검색
- [ ] 상품 페이지에 캐릭터·브랜드 로고·유명 IP 이미지 있으면 즉시 제외
- [ ] 쿠팡 동일 키워드에 등록 브랜드 상품이 이미 있으면 유사 소싱 중단
- [ ] 1688 셀러에게 권리 없음 서면 확인 + 캡처 보관

> 중국 법과 한국 법은 다름. 한국 시장 권리 침해는 **한국 법 기준**.
