배경: 온크트리 AI 상세페이지 대결 영상 벤치마크(위키 [[상세페이지 AI 냄새 신호]]) — 구조 층위 AI 냄새(번호 배지·구분선·넘버링)가 현행 파이프라인의 공백으로 확인됨.

## 목표

1. PRO 상세페이지 파이프라인에서 "AI가 만든 냄새"를 구조 층위에서 제거한다.
2. 개선된 파이프라인의 첫 실전 산출물로 보태니컬 비누(쿠팡 16202992314) 상세를 전면 리뉴얼한다.
3. 현행/개선 렌더 전후 비교본으로 개선 효과를 실측한다.

## 파이프라인 변경 5건

### 1. 선형 아이콘 라이브러리 (신규 `src/lib/detail-page/icon-library.ts`)

- Lucide(ISC) 서브셋 ~40종을 인라인 SVG 상수로 임베드. 규격: stroke 2px, `fill="none"`, `stroke="currentColor"`, viewBox 24×24.
- 분류: 계절/기간 · 재질/성분 · 세척/관리 · 보관 · 용량/구성 · 배송/포장 · 사용감(보습·향·거품·순함) · 의류(핏·기장·신축 — 자작).
- API: `getIcon(key: string, size?: number): string | null` — 유효하지 않은 키는 null.
- `generate-pro-layout` system-prompt DESIGN RULE 10 개정: icon 필드에 **라이브러리 키**를 넣도록 하고 사용 가능 키 목록을 프롬프트에 제공. 이모지는 계속 금지.
- `section-renderer.ts` `icon_grid`: 유효 키 → 선형 아이콘, 무효/빈 키 → 기존 번호 배지 폴백.
- `layout-validator.ts`: 무효 icon 키 warning (autoFix: 빈 문자열로 치환 → 폴백).

### 2. 구분선 제거 + 배경 리듬

- `section-renderer.ts` divider 블록: 선(border) 렌더를 수직 여백으로 대체.
- 섹션 배경 교대: 팔레트 기반 base → tint → base → dark accent(페이지당 1회) 로테이션. `wrap-rendered.ts` 또는 렌더러에서 섹션 컨테이너 background 지정.
- system-prompt에 divider 사용 억제 문구 추가.

### 3. 넘버링 나열 금지

- system-prompt: "첫 번째 고민/두 번째 고민" 류 순번 나열 금지 명문화.
- `narrative.ts`: 정규식 warning `(첫|두|세|네)\s*번째\s*(고민|장점|이유|문제)` 검출.

### 4. 훅 대형 타이포

- hero 헤드라인 clamp 상향. 390px 모바일 기준으로 실측 후 확정 (예: `clamp(26px, 7vw, 40px)`), 1.8배 스케일 규칙과의 상호작용 확인 필수.

### 5. 팔레트 → 씬 이미지 프롬프트 주입

- `generate-scene-image` 호출 시 palette-config의 주조색을 톤 힌트로 프롬프트에 추가. 미장센 규칙(앵글·조명)은 불변.
