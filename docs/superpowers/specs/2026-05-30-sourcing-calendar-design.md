# 소싱 캘린더 (Sourcing Calendar) — 설계 문서

Generated by /brainstorming on 2026-05-30
Status: APPROVED

---

## Problem Statement

소싱 키워드 발굴 시 "지금 당장"이 아니라 "2개월 뒤"에 팔릴 상품을 미리 파악하기 어렵다.
Naver DataLab에는 24개월 이상의 과거 트렌드 데이터가 있어 계절성 패턴 분석이 가능하다.
이 데이터를 활용해 현재 시점 기준으로 2개월 후 인기 키워드를 자동으로 예측하는 기능이 필요하다.

---

## Solution

소싱 검증기(`sourcing-validator`) 앱에 새 탭으로 추가되는 **소싱 캘린더** 페이지.
카테고리 프리셋 + 커스텀 키워드 목록에 대해 DataLab 24개월 트렌드를 일괄 조회하고,
2개월 후 계절 점수를 계산해 리스트 형태로 표시한다.

- `/calendar` 라우트 (별도 페이지)
- 수동 분석 (버튼 클릭 시 전체 키워드 일괄 조회)
- localStorage 기반 (DB 없음)
- 카테고리 프리셋 + 커스텀 키워드 편집 가능

## 예측 알고리즘

### DataLab 24개월 조회

`fetchDatalabTrend24`: 기존 `fetchDatalabTrend`와 동일하지만 기간을 24개월로 확장.

```
trend[0]  = 24개월 전
trend[11] = 13개월 전 (작년 이맘때)
trend[12] = 12개월 전 (작년)
trend[13] = 11개월 전 (작년의 "현재+2개월")   ← 예측 기준값
...
trend[23] = 지난달
```

`targetOffset = 2` (현재 기준 +2개월)

### 계절 점수 계산

```typescript
// 작년 "현재+2개월" 값을 현재 YoY 성장률로 보정
function computeSeasonalScore(trend: TrendPoint[], targetOffset: number = 2): SeasonalResult {
  if (trend.length < 24) throw new Error('24개월 데이터 필요');

  const targetLastYear = trend[trend.length - (13 - targetOffset)].ratio;
  const currentMonth   = trend[trend.length - 1].ratio;
  const lastYearSame   = trend[trend.length - 13].ratio;

  const yoyGrowth = lastYearSame > 0
    ? (currentMonth - lastYearSame) / lastYearSame
    : 0;

  const predicted = clamp(Math.round(targetLastYear * (1 + yoyGrowth)), 0, 100);

  return {
    predicted,
    targetLastYear,
    yoyGrowth,
    stars: toStars(predicted),
    sparkline: trend.slice(trend.length - 12),
  };
}

function toStars(score: number): number {
  if (score <= 20) return 1;
  if (score <= 40) return 2;
  if (score <= 60) return 3;
  if (score <= 80) return 4;
  return 5;
}

function clamp(n: number, min: number, max: number): number {
  return Math.min(Math.max(n, min), max);
}
```

### 스파크라인

SVG 기반, 외부 라이브러리 없이 구현. `trend.slice(-12)` (최근 12개월) 기준.
viewBox `0 0 60 20`, polyline으로 렌더링.

## 데이터 타입

```typescript
// src/lib/seasonal.ts
export interface SeasonalResult {
  keyword: string;
  predicted: number;      // 0-100
  targetLastYear: number; // DataLab ratio
  yoyGrowth: number;      // 소수 (예: 0.23 = +23%)
  stars: number;          // 1-5
  sparkline: TrendPoint[]; // 최근 12개월
}

export interface Category {
  id: string;
  name: string;
  keywords: string[];
}
```

## API

### POST `/api/calendar/analyze`

Request:
```json
{ "keywords": ["선풍기", "아이스팩", "텀블러"] }
```

Response:
```json
{
  "results": [
    {
      "keyword": "선풍기",
      "predicted": 87,
      "targetLastYear": 82,
      "yoyGrowth": 0.06,
      "stars": 5,
      "sparkline": [{ "period": "2025-06", "ratio": 45 }, ...]
    }
  ],
  "analyzedAt": "2026-05-30T14:23:00Z"
}
```

에러 시 개별 키워드는 `error: string` 필드로 처리 (전체 실패 아님).

## Constraints

- 로컬 전용 — 배포 없음
- DB 없음 — localStorage만 사용
- 신규 Naver API 키 불필요 — 기존 `.env.local` 재사용
- Claude 분석 없음 — 알고리즘 기반 점수 계산 (API 비용 0)

## Success Criteria

- 카테고리 선택 후 "분석하기" 클릭 → 30초 내 전체 키워드 점수 표시
- 스파크라인으로 계절성 패턴 시각적 확인
- ★점수 + YoY% 로 한눈에 우선순위 파악
- 키워드/카테고리 편집 후 localStorage에 즉시 저장
