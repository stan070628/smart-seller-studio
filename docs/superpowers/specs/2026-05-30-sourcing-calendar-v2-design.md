# 소싱 캘린더 V2 (AI 키워드 추천) — 설계 문서

Generated by /brainstorming on 2026-05-30
Status: APPROVED

---

## Problem Statement

기존 소싱 캘린더(V1)는 사용자가 키워드를 직접 입력해야 한다.
소싱 초보자는 어떤 키워드를 분석해야 할지 모르고, 숙련자도 트렌드 키워드를 찾는 데 시간이 걸린다.
AI가 카테고리 기반으로 깊이 있는 서브키워드(예: "사무실 텀블러", "차량용 텀블러")를 자동 추천하면
소싱 후보 발굴 시간을 대폭 줄일 수 있다.

---

## Solution

소싱 캘린더를 **"카테고리 브라우징 → AI 키워드 추천 → 계절 점수"** 3단계 플로우로 전면 개편한다.

- 2-depth 카테고리 트리 (대분류 6개 × 소분류 5~7개)
- 소분류 선택 → Naver 자동완성 후보 수집 → Claude 소싱 필터링
- 추천 결과에 기존 DataLab 24개월 계절 점수 통합
- localStorage 캐시: 소분류별 추천 결과와 계절 점수를 각각 캐시

```

├── src/
│   ├── lib/
│   │   ├── categories.ts             — 2-depth 카테고리 트리 + 타입 정의 (신규)

│       │   ├── recommend/

│       │   └── analyze/
│       │       └── route.ts          — 변경 없음
│       └── calendar/
│           └── page.tsx              — 전면 재작성
```

### 데이터 흐름

```
[calendar/page.tsx]
  대분류 탭 클릭 → 소분류 그리드 표시
  소분류 클릭
    → localStorage 캐시 확인
    → 캐시 있음: 즉시 키워드 + 계절 점수 표시
    → 캐시 없음: "추천받기" 버튼 표시

  "추천받기" 클릭
    ↓ POST /api/calendar/recommend { subcategory, parentCategory }
  [api/calendar/recommend/route.ts]
    ↓ fetchAutocomplete(subcategory) → ~20개 후보
    ↓ Claude (claude-haiku-4-5-20251001): 소싱 관점 8개 필터링
    ↓ { keywords: string[] } 반환
  [calendar/page.tsx]
    ↓ localStorage 저장
    ↓ POST /api/calendar/analyze { keywords }
    ↓ 계절 점수 배열 반환
    ↓ localStorage 저장
    ↓ 점수 기준 내림차순 정렬 → 테이블 렌더링
```

## API

### POST `/api/calendar/recommend`

Request:
```json
{ "subcategory": "텀블러", "parentCategory": "잡화" }
```

Response:
```json
{
  "keywords": ["사무실 텀블러", "차량용 텀블러", "캠핑용 텀블러", ...],
  "recommendedAt": "2026-05-30T14:23:00Z"
}
```

#### Claude 프롬프트

```
System:
당신은 쿠팡 소싱 전문가입니다.
주어진 키워드 후보 중에서 실제로 판매 가능성이 높은 것만 골라냅니다.
선별 기준:
- 구체적인 용도/대상/특징이 있는 키워드 (예: "사무실 텀블러" ✅ vs "텀블러" ❌)
- 브랜드명, 너무 일반적인 단어 제외
- 쿠팡에서 단품으로 판매 가능한 상품이어야 함

User:
대분류: {parentCategory}
소분류: {subcategory}
후보 키워드: {candidates.join(', ')}

위 후보에서 소싱 관점으로 가장 유망한 8개를 골라 JSON 배열만 반환하세요.
예시 형식: ["사무실 텀블러", "차량용 텀블러"]
```

모델: `claude-haiku-4-5-20251001`

#### 에러 처리

| 상황 | 처리 |
|------|------|
| Naver 자동완성 결과 없음 | `{subcategory} + ["용", "형", "세트", "대용량", "소형"]` 조합으로 폴백 |
| Claude API 실패 | Naver 자동완성 상위 8개 그대로 반환 |
| ANTHROPIC_API_KEY 없음 | Naver 자동완성만으로 폴백, 응답에 `"fallback": true` 포함 |

### 버튼 상태

- **[추천받기]**: 캐시 없을 때만 표시. 클릭 시 recommend → analyze 순차 실행.
- **[새로 추천받기]**: 캐시 있을 때 표시. 기존 캐시 무시하고 재실행.
- **[분석하기]**: 추천 완료 후 표시. 계절 점수만 다시 계산(키워드 재사용).
- **[카테고리 편집]**: 소분류 추가/삭제 가능한 편집 패널 토글.

### 로딩 상태

- 추천 중: "키워드 추천 중..." (스피너)
- 분석 중: "계절 점수 분석 중..." (프로그레스)
- 폴백 발생 시: 상단 배너 "Claude API 없이 Naver 자동완성만으로 추천했습니다"

## Constraints

- 로컬 전용 — 배포 없음
- DB 없음 — localStorage만 사용
- Claude Haiku 사용 — 키워드 8개 필터링에 최적화, 비용 최소화

## Success Criteria

- 소분류 클릭 → "추천받기" 버튼 클릭 → 20초 내 키워드 8개 + 계절 점수 표시
- 두 번째 방문 시 localStorage 캐시에서 즉시 로드
- Claude API 없어도 Naver 자동완성 폴백으로 동작
- 소분류 추가/삭제 후 localStorage에 즉시 저장
