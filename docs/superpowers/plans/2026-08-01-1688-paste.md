# 1688 붙여넣기로 두 공급처 원가 비교 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 소싱리스트 항목에 1688 결제 확인 화면을 붙여넣으면 개당 원가가 계산·저장되어, 도매꾹 원가와 나란히 판정을 비교할 수 있게 한다.

**Architecture:** 순수 함수 파서가 `价格明细` 블록을 읽어 검산 두 갈래로 검증한 뒤, 통과분만 `sourcing_shortlist`에 입력값으로 저장한다. 원가는 조회 시점에 기존 `calcImportTax`·`breakEvenPrice`로 계산한다. UI는 평면 표에 행 확장을 더해 두 공급처를 나란히 세운다.

**Tech Stack:** Next.js App Router, TypeScript, Vitest, Postgres(`getSourcingPool`)

## 배경

1688에서 가격을 볼 수 있는 화면 셋을 실측 비교해 **결제 확인 화면**을 골랐다.

| 화면 | 개당가 확정 | 아직 안 샀나 | 원화 |
|---|---|---|---|
| 장바구니 | ❌ 체크할 때마다 변동 | ✅ | ❌ |
| **결제 확인** | ✅ | ✅ | ✅ |
| 주문 내역 | ✅ | ❌ 결제 후 | ✅ |

장바구니는 주문 단위 할인이 품목별로 분배돼 **품목을 체크하면 개당가가 바뀐다**(실측 `3.50 → 4.00`). 주문 내역은 결제 후에만 보인다.

`src/lib/sourcing/parse-1688-checkout.ts` 신규 생성:

```typescript
/**
 * 1688 결제 확인 화면 붙여넣기 파서.
 *
 * 왜 결제 확인 화면인가 (2026-08-01 실측 비교):
 *   장바구니 — 주문 단위 할인이 품목별로 분배돼 품목을 체크하면 개당가가 바뀐다(3.50 → 4.00).
 *   주문 내역 — 결제 후에만 보여 살지 말지 판단에 못 쓴다.
 *   결제 확인 — 값이 확정되고 아직 안 샀으며 원화까지 있다. 이 화면만 셋을 다 만족한다.
 *
 * 우측 `价格明细` 블록만 읽는다. 판매자별 `店铺明细`는 무시한다 — 판매자가 몇이든
 * 전체 합계는 `价格明细` 한 곳에 있고, 실측에서 판매자별 합이 전체와 일치했다.
 *
 * 단가가 아니라 `小计`를 읽는다. `券后价`가 없는 품목이 있다(실측 샘플3 판매자A).
 * `小计`는 쿠폰이 이미 반영된 값이라 유무를 신경 쓸 필요가 없다.
 */

export interface Parsed1688Item {
  /** 옵션명 (색상·사이즈) */
  option: string;
  qty: number;
  /** 小计 — 쿠폰 반영 후 상품 소계 */
  subtotalCny: number;
}

export interface Parsed1688 {
  ok: boolean;
  /** ok가 false일 때 사람에게 보여줄 사유 */
  error: string | null;

  totalCny: number | null;
  totalKrw: number | null;
  goodsCny: number | null;
  freightCny: number | null;
  discountCny: number | null;
  qty: number | null;
  items: Parsed1688Item[];

  /** ₩ ÷ ¥合计. 그 주문에 실제 적용된 환율 */
  exchangeRate: number | null;
  /** ₩合计 ÷ 총 수량 */
  unitKrw: number | null;
}

/** 검산 허용 오차 — 표시가 소수 2자리라 반올림 잔차만 허용한다 */
const EPSILON = 0.02;

function toNum(raw: string | undefined): number | null {
  if (!raw) return null;
  const n = Number.parseFloat(raw.replace(/,/g, ''));
  return Number.isFinite(n) ? n : null;
}

function fail(reason: string): Parsed1688 {
  return {
    ok: false, error: reason,
    totalCny: null, totalKrw: null, goodsCny: null, freightCny: null,
    discountCny: null, qty: null, items: [],
    exchangeRate: null, unitKrw: null,
  };
}

export function parse1688Checkout(text: string): Parsed1688 {
  if (!text || !text.trim()) return fail('붙여넣은 내용이 없습니다.');

  // 전각 공백·NBSP를 보통 공백으로 — 복사 경로에 따라 섞여 들어온다
  const t = text.replace(/[ 　]/g, ' ');

  const totalCny = toNum(t.match(/合计[^\d¥￥]{0,12}[¥￥]\s*([\d,]+(?:\.\d+)?)/)?.[1]);
  const totalKrw = toNum(t.match(/₩\s*([\d,]+(?:\.\d+)?)/)?.[1]);
  const goodsCny = toNum(t.match(/商品总计[^¥￥\n]{0,24}[¥￥]\s*([\d,]+(?:\.\d+)?)/)?.[1]);
  const freightCny = toNum(t.match(/总运费[^\d¥￥]{0,12}[¥￥]\s*([\d,]+(?:\.\d+)?)/)?.[1]);
  const qty = toNum(t.match(/商品总计\s*\d+\s*种\s*(\d+)\s*件/)?.[1]);

  // 店铺优惠는 금액이 아닐 수 있다 — 包邮(무료배송) 같은 값이 온다.
  // 못 읽으면 0으로 치지 말고 null로 두어 검산이 판단하게 한다.
  const discountCny = toNum(t.match(/店铺优惠[^\n]{0,20}?减\s*[¥￥]\s*([\d,]+(?:\.\d+)?)/)?.[1]);

  if (totalCny === null) {
    return fail('합계(合计)를 찾지 못했습니다. 우측 가격 영역까지 포함해 다시 긁어와 주세요.');
  }
  if (totalKrw === null) {
    return fail('원화 금액을 찾지 못했습니다. 장바구니가 아니라 결제 확인 화면을 긁어와 주세요.');
  }
  if (qty === null) {
    return fail('수량(商品总计 N种N件)을 찾지 못했습니다.');
  }

  const items = parseItems(t);

  // 검산 ① Σ小计 + 总运费 = 合计
  // 小计는 상품 소계이고 배송비는 별도로 얹힌다. 무료배송 주문만 보면
  // 运费가 0이라 이 항을 빠뜨리기 쉽다 — 실제로 초안이 그랬다.
  const sumSub = items.reduce((a, i) => a + i.subtotalCny, 0);
  const check1 = items.length > 0 && freightCny !== null
    && Math.abs(sumSub + freightCny - totalCny) < EPSILON;

  // 검산 ② 商品总计 − 店铺优惠 + 总运费 = 合计
  const check2 = goodsCny !== null && freightCny !== null && discountCny !== null
    && Math.abs(goodsCny - discountCny + freightCny - totalCny) < EPSILON;

  if (!check1 && !check2) {
    return fail(
      '검산이 맞지 않습니다. 숫자를 잘못 읽었을 수 있어 저장하지 않습니다. ' +
      '결제 확인 화면 전체(좌측 품목 + 우측 가격명세)를 긁어와 주세요.',
    );
  }

  return {
    ok: true, error: null,
    totalCny, totalKrw, goodsCny, freightCny, discountCny, qty, items,
    exchangeRate: totalCny > 0 ? totalKrw / totalCny : null,
    unitKrw: qty > 0 ? Math.round(totalKrw / qty) : null,
  };
}

/** 옵션 줄(颜色:…)마다 뒤따르는 마지막 금액을 小计로 본다 */
function parseItems(t: string): Parsed1688Item[] {
  const out: Parsed1688Item[] = [];
  const re = /颜色\s*[:：]\s*([^\n]+)/g;
  let m: RegExpExecArray | null;

  while ((m = re.exec(t)) !== null) {
    const block = t.slice(m.index, m.index + 300);
    const qty = toNum(block.match(/\n\s*(\d+)\s*\n/)?.[1]) ?? 1;
    const prices = block.match(/[¥￥]\s*[\d,]+(?:\.\d+)?/g) ?? [];
    const last = prices.length ? toNum(prices[prices.length - 1].replace(/[¥￥]\s*/, '')) : null;
    if (last === null) continue;

    out.push({
      option: m[1].replace(/\s*预计.*$/, '').trim(),
      qty,
      subtotalCny: last,
    });
  }
  return out;
}
```

```typescript
 * 1688 사입 원가 계산.
 *

 * 저장된 원가가 조용히 낡는다. (선행 작업에서 verified_at이 같은 문제를 냈다)
 *
 * 중국 내 배송비는 이미 buyKrwTotal(合计의 원화)에 포함돼 있다.
 * 여기서 더하는 intlShipPerUnitKrw는 배대지 → 한국 구간이다.
 */

import { calcImportTax, getTariffRate } from '@/lib/sourcing/tariff';
import { breakEvenPrice } from '@/lib/sourcing/coupang-price';
import type { LogisticsSize } from '@/types/shortlist';

export interface Cost1688Input {
  /** 붙여넣기의 원화 합계 (中国内 배송비 포함) */
  buyKrwTotal: number;
  /** 주문 총 수량 */
  orderQty: number;
  /** 개당 국제배송비 — 배대지 → 한국 */
  intlShipPerUnitKrw: number;
  /** 관세율 판단용. 상품명이 없으면 null */
  itemName: string | null;
  logisticsSize: LogisticsSize;
}

export interface Cost1688Result {
  unitKrw: number | null;
  dutiableValueKrw: number | null;
  tariffRate: number;
  tariffKrw: number | null;
  importVatKrw: number | null;
  effectiveCostKrw: number | null;
  breakEvenPriceKrw: number | null;
  /** 국제배송비가 0이라 원가가 낙관적으로 낮다 */
  shippingMissing: boolean;
}

export function calc1688UnitCost(input: Cost1688Input): Cost1688Result {
  const tariffRate = getTariffRate(input.itemName);
  const shippingMissing = input.intlShipPerUnitKrw <= 0;

  if (input.orderQty <= 0 || input.buyKrwTotal <= 0) {
    return {
      unitKrw: null, dutiableValueKrw: null, tariffRate,
      tariffKrw: null, importVatKrw: null,
      effectiveCostKrw: null, breakEvenPriceKrw: null, shippingMissing,
    };
  }

  const unitKrw = Math.round(input.buyKrwTotal / input.orderQty);
  const tax = calcImportTax({
    goodsKrw: unitKrw,
    dutiableFreightKrw: input.intlShipPerUnitKrw,
    tariffRate,
  });

  return {
    unitKrw,
    dutiableValueKrw: tax.dutiableValueKrw,
    tariffRate,
    tariffKrw: tax.tariffKrw,
    importVatKrw: tax.importVatKrw,
    effectiveCostKrw: tax.dutyPaidValueKrw,
    breakEvenPriceKrw: breakEvenPrice(tax.dutyPaidValueKrw, input.logisticsSize),
    shippingMissing,
  };
}
```

```tsx
import { parse1688Checkout } from '@/lib/sourcing/parse-1688-checkout';
import { calc1688UnitCost } from '@/lib/sourcing/cost-1688';

function SupplierCompare({
  item, onPatch,
}: {
  item: ShortlistItem;
  onPatch: (itemNo: number, body: Record<string, unknown>) => Promise<void>;
}) {
  const [paste, setPaste] = useState('');
  const [parsed, setParsed] = useState<ReturnType<typeof parse1688Checkout> | null>(null);
  const [saving, setSaving] = useState(false);
  const [err, setErr] = useState<string | null>(null);

  const ship = item.intlShipPerUnit ?? 0;
  const saved = item.buyKrwTotal !== null && item.orderQty1688 !== null;

  const cost = saved
    ? calc1688UnitCost({
        buyKrwTotal: item.buyKrwTotal!,
        orderQty: item.orderQty1688!,
        intlShipPerUnitKrw: ship,
        itemName: item.title,
        logisticsSize: item.logisticsSize,
      })
    : null;

  async function save() {
    if (!parsed?.ok) return;
    setSaving(true); setErr(null);
    try {
      await onPatch(item.itemNo, {
        buyKrwTotal: parsed.totalKrw,
        buyCnyTotal: parsed.totalCny,
        orderQty1688: parsed.qty,
        exchangeRate1688: parsed.exchangeRate,
      });
      setPaste(''); setParsed(null);
    } catch (e) {
      setErr(e instanceof Error ? e.message : '저장하지 못했습니다.');
    } finally {
      setSaving(false);
    }
  }

  return (/* 목업 구조: 도매꾹 줄 · 1688 줄 · 붙여넣기 · 검산 · 국제배송비 */);
}
```

수동 검증에서 고칠 것이 나오면 수정 후 커밋한다. 없으면 건너뛴다.
