구현 방법

① PNG 이미지 저장

라이브러리: html2canvas (이미 html2pdf.js에 포함)
흐름:
1. EventCardPreview 컴포넌트를 숨겨진 div에 렌더링
2. html2canvas로 캡처 (scale: 2, 고해상도)
3. canvas.toBlob() → PNG 다운로드

또는: 기존 generatePdf 방식 대신
/api/label/generate-image 서버 API 호출
→ Sharp로 렌더링 (향후 서버사이드 방식)

② 상세 HTML 최상단 삽입

핵심 코드:
const eventHtml = getEventCardHtml(fields);
const merged = eventHtml + generatedDetailHtml;
updateAssetsDraft({ generatedDetailHtml: merged });

getEventCardHtml():
EventCard 컴포넌트를 renderToStaticMarkup으로
정적 HTML 문자열로 변환하거나, 또는
별도 HTML 템플릿 함수로 직접 생성

③ 이미 생성된 상세 HTML에 리뷰 섹션 추가 방법

클라이언트에서 직접:
1. AssetsResultPanel에서 generatedDetailHtml 상태 앞에
   이벤트 카드 HTML 블록을 prepend
2. 상태 업데이트 → iframe이 자동으로 다시 렌더링됨
3. ZIP 다운로드 시 merged HTML이 포함됨

되돌리기: undo 패턴 (prevHtmlRef 방식 재사용)
